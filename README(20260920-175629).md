# Prostate MRI AI and ProstateAgent

Research code for T2-weighted prostate MRI classification, external evaluation, neural distillation, and computational interpretability. This repository contains earlier image-classification experiments and the later ProstateAgent analysis workflows.

**Research demonstration only.** Clinical utility and prospective patient benefit have not been established. Computational explanations describe model behaviour; they do not establish biological mechanisms or identify a tumour boundary.

## Running the recovered Colab workflows

1. Download and extract `ProstateAgent_Recovered_Colab_Code.zip`.
2. Read the extracted `README.md` for input files, checkpoints, and execution dependencies.
3. In [Google Colab](https://colab.research.google.com/), choose **File > Upload notebook** and select the relevant `.ipynb` from `notebooks/`.
4. Select a GPU runtime for neural-model workflows, provide the specified inputs, and follow the notebook cells in order.

| Notebook | Workflow |
|---|---|
| `01_Internal_TrackB_Training.ipynb` | Internal Track-B training |
| `02_Internal_OOF_GradCAM.ipynb` | Out-of-fold evaluation and Grad-CAM |
| `03_Mechanistic_Audit_and_Neural_Distillation.ipynb` | Model restoration, computational audit, and neural distillation |
| `04_Final_Surrogate_Search_Formulas_Trees.ipynb` | Interpretable surrogate search, formulas, and trees |
| `05_VolumeMIL_Training_Continuation.ipynb` | Volume-model training continuation; prior runtime state is required |
| `06_UCLA_Exploratory_16View_TTA.ipynb` | Exploratory test-time augmentation (TTA) |
| `07_PROMIS_Precursor_External.ipynb` | External-evaluation workflow for an earlier model version |

These are recovered research workflows, not a single turnkey pipeline. Some require saved weights, prepared features, or previous runtime state. The recovered bundle excludes those large inputs. Syntax and notebook structure were checked during packaging; complete training was not rerun, and a fresh-runtime reproduction is not guaranteed. Original notebook installation cells and the bundle instructions document dependencies; no universally validated package-version lock is supplied.

## Model interpretation and evaluation

The analysis workflows include neural student models, additive and symbolic surrogates, rule trees, and Grad-CAM. The linked application presents an inference/explanation workflow with input and output quality checks.

- **AUC** measures discrimination against outcome labels. **Distillation R²** measures agreement with teacher scores; it is not cancer-detection accuracy.
- A readable surrogate has its own measured fidelity. A neural student's R² must not be assigned to a different tree or formula.
- TTA means **test-time augmentation**. The exploratory UCLA TTA analysis is separate from the primary held-out evaluation and is not a new independent test cohort.
- Recorded metrics in `recorded_metrics/` belong to their named model versions and evaluation protocols. Consult the bundled provenance and limitations before citing them.
- Comparisons with human readers evaluated on different cases are descriptive, not paired evidence of superiority.

## Data and model availability

Image archives already present in this repository are separate from the recovered code bundle. Public external cohorts must be obtained under their respective access conditions. Do not infer patient counts from image counts or assume that differently named archives are disjoint cohorts. Checkpoints and intermediate files required for exact reproduction are identified in the individual workflows; the code bundle alone does not contain every trained model.
